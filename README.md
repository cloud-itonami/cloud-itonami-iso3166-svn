# cloud-itonami-iso3166-svn

Open ISO 3166 Blueprint for **SVN**: Republic of Slovenia.

Independent public-sector market-entry & procurement-compliance service
for an already-incorporated operator entering public contracts in Slovenia.

## Official surface

- Procurement: EJN (Elektronsko javno naročanje) public e-procurement portal
- Business/tax: AJPES business register + tax number
